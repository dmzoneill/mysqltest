# mysqltest

A small VB.NET Windows Forms program for testing a MySQL connection.

## What it does

It builds a connection string from the server, user and password, opens the
connection and reports whether it succeeded or shows the error.

## Tech

- Visual Basic .NET (Windows Forms)
- MySQL Connector/NET

## Building

Open the `.sln` file in Visual Studio and build it. Windows only.
